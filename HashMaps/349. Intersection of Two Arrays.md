
# 349. Intersection of Two Arrays

Given two integer arrays nums1 and nums2, return an array of their intersection. Each element in the result must be unique and you may return the result in any order.

 

Example 1:

Input: nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2]


## Problem Link

https://leetcode.com/problems/intersection-of-two-arrays/description/ 


## Code

```java

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        
        HashMap <Integer,Boolean> memo = new HashMap<Integer, Boolean> ();

        for (int currentNums : nums1)
         {
         // using foe loop to interarte in nums1 array

        if (!memo.containsKey(currentNums))
         {
        //check that does the hash map have the current iterated number if not 

        memo.put(currentNums,true);
        // then put it in Hash map 
         }

         }

    ArrayList <Integer> answer = new ArrayList<>();
    // Answer is needed in Integer

    for (int currentNums : nums2)
     {
        // now doing it for nums2 array

        if (memo.containsKey(currentNums) && memo.get(currentNums))
        // Is number repeating in array of nums2 and nums1
         {
           answer.add(currentNums);
           // adding it to array as repeated

           memo.put(currentNums,false);
           // now doing it false so doesn't repeat again
        }
    }
        int[] result = new int [answer.size()];
        // ARRAY LIST ARE OBJECTS AND WE NEED INTEGER SO CONVERT IT INTO ARRAY  

        for (int i = 0; i<answer.size();i++)
        result[i] = answer.get(i);
        // result updated
        return result;
    }
}
